The issue in `shop/cart.py` is that the `add` method overwrites the quantity for a given SKU each time it is called. To fix this, we need to update the quantity instead of overwriting it. Here is the corrected code:

```python
class Cart:
    def __init__(self, inventory):
        self.inventory = inventory
        self.lines = {}

    def add(self, sku, qty=1):
        if sku in self.lines:
            self.lines[sku] += qty
        else:
            self.lines[sku] = qty

    def total(self):
        return round(
            sum(bulk_price(self.inventory.get(s)['price'], q) for s, q in self.lines.items()), 2
        )
```
