The Cart class has been implemented with the following features:

1. **`apply_coupon(code)`** - Applies a coupon code to the cart
   - `SAVE10`: Takes 10% off the cart total
   - `FIVEOFF`: Takes $5 off the cart total
   - Unknown codes raise `ValueError`

2. **`total()`** - Returns the cart total including any applied coupon
   - Uses `max(0, ...)` to ensure the total never goes below 0

3. **Additional methods** for a complete cart implementation:
   - `add_item(name, price)` - Add items to the cart
   - `remove_item(name)` - Remove items by name
   - `clear()` - Clear all items and coupons
   - `__str__()` - String representation

The tests confirm:
- SAVE10 correctly applies 10% discount ($2.25 → $2.02)
- FIVEOFF correctly applies $5 discount
- Unknown coupon codes raise ValueError
- Total never goes below 0 (e.g., $3 item with FIVEOFF = $0.00)
