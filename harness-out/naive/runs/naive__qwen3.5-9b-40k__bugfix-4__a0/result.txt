The fix has been applied. The issue was in `./shop/report.py` in the `monthly` function.

**Problem:** The original code used `o["date"][5:7]` which only extracted the month portion ("01") from dates like "2025-01-05". This caused all January dates from different years to be grouped into the same "01" bucket.

**Fix:** Changed to `o["date"][:7]` which extracts the full "YYYY-MM" prefix (first 7 characters), so "2025-01-05" becomes "2025-01" and "2026-01-10" becomes "2026-01", keeping them separate.
