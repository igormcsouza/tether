I've added pagination to `Inventory.list_items` with the following changes:

**Modified `./shop/inventory.py`:**
- Added `page` keyword argument (defaults to 1, 1-indexed)
- Added `page_size` keyword argument (defaults to None, returns all items)

**Behavior:**
- `list_items()` - returns all items (backward compatible)
- `list_items(page=1, page_size=2)` - returns first 2 items
- `list_items(page=2, page_size=2)` - returns next 2 items
- `list_items(page_size=None)` - returns all items

**Backward compatibility:** Existing callers that call `list_items()` with no arguments will continue to work exactly as before, returning all sorted items.
