# AGENTS.md — mini project guide

## Mission
mini is a tiny text-statistics toolkit. Keep it dependency-free and readable.

## Workflow
1. Run `uv sync` to install the environment.
2. Run `uv run pytest` before and after every change.
3. Read `docs/architecture.md` and `docs/style.md` before editing anything.
4. Use `mem search` to recall earlier decisions.
5. Open a PR per change with a Conventional Commit title.

## Style
- Functions are small, typed and documented.
- No global state. No third-party imports.
- Keep CLI parsing in `mini/cli.py` and logic in the other modules.

## Testing
Every behaviour has a unit test in `tests/`. Golden files live in `tests/golden/`.
