# Multi-Currency Support Plan for Shop

## Overview
Add support for multiple currencies throughout the shop system, allowing prices to be stored and displayed in different currencies with optional conversion.

## Steps

1. **Define Currency Types**
   - Create a `Currency` class/enum representing supported currencies (e.g., USD, EUR, GBP)
   - Define exchange rates between currencies for conversion calculations

2. **Update Inventory Schema**
   - Modify `Inventory.add()` to accept an optional currency parameter for each item's price
   - Store prices as `(amount, currency)` tuples instead of plain numbers
   - Update `Inventory.get()` to return currency-aware price data

3. **Update Pricing Module**
   - Modify `pricing.py` to work with currency-aware unit prices
   - Add currency conversion functions when needed
   - Update `bulk_price()` to handle currency conversions for bulk discounts

4. **Update Cart Module**
   - Modify `Cart.total()` to return total in the cart's base currency (or user-selected currency)
   - Add optional currency parameter to control output currency
   - Implement automatic currency conversion if needed

5. **Update CLI/Reports**
   - Modify `report.py` to optionally convert revenue to a target currency
   - Update `cli.py` to accept a `--currency` flag for summary output
   - Add currency information to order records when loading/saving

6. **Add Currency Conversion Logic**
   - Implement exchange rate lookup and conversion functions
   - Provide default base currency (e.g., USD) for internal calculations
   - Allow configuration of supported currencies and rates

7. **Documentation**
   - Document supported currencies and exchange rates
   - Add usage examples for multi-currency operations
